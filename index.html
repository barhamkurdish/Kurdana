ژیر — یاریدەدەری زیرەکی کوردی

بپرسە، بنووسە، وەرگێڕە و بیرۆکەکانت پەرەپێبدە؛ هەمووی بە ڕووکاری کوردی و مۆدێرن.

ژیر دەتوانێت هەڵە بکات؛ پێش بڕیارێکی گرنگ، زانیارییەکان پشتڕاست بکەرەوە.

ڕێکخستن و پەیوەندی API

کلیلی API تەنها لە localStorage ـی ئەم وێبگەیەدا هەڵدەگیرێت. بۆ بەکارهێنانی production، باشترە API لە پشتەوەی server/endpoint ـێکی پارێزراوەوە بانگ بکرێت.
